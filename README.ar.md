# سرك ببير - شارك الأسرار بأمان

![GitHub release (latest SemVer)](https://img.shields.io/github/v/release/jhaals/yopass?sort=semver)

سرك ببير هي منصة مشاركة أسرار عربية الأولوية مبنية على Yopass، مصممة لمشاركة الأسرار بطريقة سريعة وآمنة.

الغرض الوحيد من سرك ببير هو تقليل كلمات المرور المتداولة في أنظمة إدارة التذاكر ورسائل Slack ورسائل البريد الإلكتروني. يتم تشفير/فك تشفير الرسائل محلياً في المتصفح وإرسالها إلى سرك ببير دون مفتاح فك التشفير، والذي يظهر مرة واحدة فقط أثناء التشفير. ثم يُرجع سرك ببير رابطاً لمرة واحدة مع تاريخ انتهاء محدد.

**متاح على [sirkbbir.com](https://sirkbbir.com)**

## المميزات الرئيسية

- **واجهة عربية كاملة**: ترجمة عربية كاملة مع دعم الكتابة من اليمين إلى اليسار (RTL)
- **تشفير من طرف إلى طرف**: يتم التشفير وفك التشفير محلياً في متصفحك باستخدام [OpenPGP](https://openpgpjs.org/)
- **المشاهدة لمرة واحدة**: يمكن مشاهدة الأسرار مرة واحدة فقط
- **التدمير الذاتي**: الرسائل لها عمر محدد ويتم حذفها تلقائياً بعد X ساعات
- **بدون حسابات**: لا حاجة لإدارة حسابات أو مستخدمين
- **خيار كلمة مرور مخصصة**: أضف طبقة أمان إضافية
- **رفع ملفات محدود**: لمشاركة الملفات الصغيرة بشكل آمن
- **مفتوح المصدر**: شفافية كاملة وقابلية للمراجعة

## كيف يعمل

1. **قم بإنشاء سر**: أدخل رسالتك أو ارفع ملفاً صغيراً
2. **اختر الإعدادات**: حدد مدة الصلاحية (ساعة، يوم، أسبوع) وفعّل خيار "المشاهدة لمرة واحدة" إذا أردت
3. **احصل على الرابط**: سيتم تشفير السر محلياً وستحصل على:
   - رابط بنقرة واحدة (يحتوي على مفتاح فك التشفير في الرابط)
   - رابط قصير + مفتاح فك التشفير منفصل (للأمان الإضافي)
4. **شارك بأمان**: أرسل الرابط للمستلم عبر قناة اتصال

## التثبيت والإعداد

### Docker Compose

استخدم ملف Docker Compose في دليل `deploy/docker-compose/` لإعداد نسخة من سرك ببير.

```bash
cd deploy/docker-compose/insecure
docker-compose up -d
```

### Docker

بدون تشفير TLS (يحتاج إلى reverse proxy للتشفير):

```bash
docker run --name memcached_sirkbbir -d memcached
docker run -p 127.0.0.1:80:1337 --link memcached_sirkbbir:memcached -d jhaals/yopass --memcached=memcached:11211
```

ثم وجه reverse proxy الذي يتعامل مع اتصالات TLS إلى `127.0.0.1:80`.

## التقنيات المستخدمة

- **الواجهة الأمامية**: React مع TypeScript، Vite، TailwindCSS
- **الواجهة الخلفية**: Go
- **قاعدة البيانات**: Redis أو Memcached
- **التشفير**: OpenPGP.js
- **الترجمة**: i18next مع دعم كامل للعربية

## إعدادات الخادم

خيارات سطر الأوامر:

```console
$ yopass-server -h
      --address string             عنوان الاستماع (الافتراضي 0.0.0.0)
      --database string            قاعدة البيانات الخلفية ('memcached' أو 'redis') (الافتراضي "memcached")
      --max-length int             الحد الأقصى لطول السر المشفر (الافتراضي 10000)
      --memcached string           عنوان Memcached (الافتراضي "localhost:11211")
      --metrics-port int           منفذ استماع خادم المقاييس (الافتراضي -1)
      --port int                   منفذ الاستماع (الافتراضي 1337)
      --redis string               عنوان Redis URL (الافتراضي "redis://localhost:6379/0")
      --tls-cert string            مسار شهادة TLS
      --tls-key string             مسار مفتاح TLS
      --cors-allow-origin          إعداد Access-Control-Allow-Origin CORS (الافتراضي *)
      --force-onetime-secrets      رفض إنشاء أسرار غير محددة بمرة واحدة
      --disable-upload             تعطيل نقاط النهاية /file للرفع
```

يمكن تخزين الأسرار المشفرة إما في Memcached أو Redis عن طريق تغيير علامة `--database`.

## الأمان

- 🔒 التشفير من طرف إلى طرف باستخدام OpenPGP
- 🔒 لا يتم تخزين مفتاح فك التشفير على الخادم أبداً
- 🔒 التدمير الذاتي التلقائي للأسرار
- 🔒 خيار المشاهدة لمرة واحدة لحماية إضافية
- 🔒 لا يتم تسجيل أو تخزين أي معلومات شخصية
